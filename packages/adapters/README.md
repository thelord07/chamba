# @chamba/adapters

Node implementations of the [`@chamba/core`](https://www.npmjs.com/package/@chamba/core)
ports: `NodeFilesystem`, `NodeProcess`, `SystemClock`.

Used by [`@chamba/mcp`](https://www.npmjs.com/package/@chamba/mcp) to wire chamba's
pure core to the real filesystem, git and clock. Most users want the MCP server, not
this package directly.
